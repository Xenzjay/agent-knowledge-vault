# 初始化与定制

## 创建工作区

PowerShell 7+：

```powershell
pwsh -NoProfile -File .\scripts\bootstrap.ps1 -Target "D:\KnowledgeWorkspace"
```

默认创建完整的大区和二级分类。可选主题目录需要显式启用：

```powershell
pwsh -NoProfile -File .\scripts\bootstrap.ps1 -Target "D:\KnowledgeWorkspace" -IncludeSuggestedSubgroups
```

目标目录非空时，初始化默认停止。确认需要合并时使用 `-Force`：脚本会创建缺失目录，并覆盖 `目录结构.md`、`AGENTS.md`、`工作区导航.md` 以及 `_模板` 中的同名模板；目标目录中的其他文件不会被删除或覆盖。

初始化后的目录可以直接用 Obsidian 打开，也可以作为普通 Markdown 文件夹交给 Agent。两种方式共用目录、模板和 `AGENTS.md`，区别只在于使用工具，不需要维护两套分类。

## 定制分类

1. 在 `manifest/vault-manifest.json` 中添加、删除或调整大区和分类。
2. 修改 `manifest/routing-rules.yaml`，让新内容路由到有效目录。
3. 按需要调整 `templates/` 与 `vault/AGENTS.md`。
4. 运行校验脚本，并在临时目录测试初始化。

建议使用以下命令完成校验：

```powershell
pwsh -NoProfile -File .\scripts\validate.ps1
pwsh -NoProfile -File .\scripts\smoke-test.ps1
```

## 迁移已有资料

先备份，再按大区分批整理；每批检查文件链接和附件引用。避免一次性重命名大量目录。敏感内容留在本地受控存储，不放入不适当的同步或版本控制范围。
