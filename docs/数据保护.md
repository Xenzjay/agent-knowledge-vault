# 数据保护

## 数据分级

- 通用：可公开的知识、资源链接和不含个人信息的说明。
- 个人：身份资料、通信信息、私人关系、日常记录。
- 敏感：认证凭据、财务、医疗信息、精确位置及可进入系统的基础设施信息。

## 存储原则

- 根据数据敏感程度选择本地、加密、同步和备份方式。
- 不在普通笔记、示例或脚本中保存密码、Token、API Key、Cookie 或私钥。
- 账号记录不存明文密码；使用密码管理器并只保留必要引用。
- 财务和医疗资料采用最小化记录，并控制同步和共享范围。
- 分享或提交资料前检查身份信息、真实路径、附件和版本历史。

## 凭据暴露处理

若凭据曾进入版本历史，删除当前文件并不足够；应立即轮换凭据，再按托管平台流程清理历史记录。
