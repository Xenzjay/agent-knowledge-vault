# 记录协议

## 固定触发词

```text
记录：
批量记录：
暂存：
批量入库
```

## 处理方式

### `记录：`

立即处理一个或少量内容：

```text
记录：
https://github.com/example/demo
```

### `批量记录：`

一次处理多个链接、文字、图片和文档。用户不需要提前分类。

### `暂存：`

只做原始收集，放到收件箱，不建立正式资源卡。

### `批量入库`

统一处理已经暂存的内容：去重、分类、格式化、归档。

## 最小能力卡

每条资源至少记录：

- 是什么
- 能做什么
- 适用场景
- 调用方式
- 入口
- 来源
- 状态

## 记录边界

- 默认保留足以检索和采取下一步行动的信息，不复制整份外部文档。
- 多个独立资源分别建记录；同一作者或主题可用索引页汇总。
- 用户指定汇总或拆分方式时，以用户要求为准。
- 图片和文档记录在 `_附件/YYYY/`，笔记使用双链。
