# AGENTS.md

这是一个按信息领域组织的知识工作区。

## 记录协议

```text
记录：
批量记录：
暂存：
批量入库
```

资源记录优先服务 Agent 调用。每条内容至少说明：

- 是什么
- 能做什么
- 适用场景
- 调用方式
- 入口

## 目录原则

- 一级目录表示信息大区。
- 二级目录表示稳定主题。
- 仅在主题需要独立检索、维护、项目隔离或数据访问边界时增加下一级目录。
- `归档` 用于已完成或停止维护的资料。
- `待整理区` 是临时队列，应定期清理。
- 不为“最近”“重要”等状态创建目录。

## 数据保护

账号、财务、医疗和基础设施信息按其敏感程度限制访问和同步。不要在笔记中保存明文密码、Token、API Key 或私钥。
